# Ghostly

A chrome extension that lets you watch instagram stories and read DMs without being seen.

Made by Gaurab Pantha, Nepal. Built for Hack Club.

## What it does

- Hides your name from story viewers
- Hides "Seen" on DMs
- Hides "Typing..."

One button turns it on or off, and 3 switches let you pick what to hide. The popup also has a counter for how many times it hid something.

## Install

1. Unzip the folder
2. Go to `chrome://extensions`
3. Turn on Developer mode
4. Click Load unpacked and select the folder with `manifest.json`
5. Reload instagram if it was already open

Green button = on. Grey = off.

## Things that dont work perfectly

- Stories work best
- DM seen and typing are best effort. Instagram sends some of it a way I cant block, so it might still leak. Test with a friend first
- If instagram changes how it works, this can break
- Not affiliated with instagram and it might break their rules. Use at your own risk
- If ghost mode is off when you view a story, they see you

## Privacy

No server, no password, nothing leaves your browser. It only runs on instagram.com.

## Not working?

Reload the instagram tab first, thats the usual problem. Then check the button is green and the counter goes up when you view a story.
